# 指導教授研究驗收說明

[原始研究規格](../../docs/EVENING_FULL_TEST_PLAN_2026-11-22.md) 記錄試驗方法與門檻。[T00～T11 逐項驗收矩陣](../../docs/T00_T11_EXTERNAL_OPERATIONS_2026_11_23.md) 記錄現行技術證據和各項正式結案條件。

| 要回答的問題 | 驗收證據 |
|---|---|
| T00～T02 來源可信、字典可泛化 | 原始 SHA 和版本日期、互斥切分、跨來源逐列材料正解、對應精確率／覆蓋率與學習曲線。 |
| T03 人工時間與品質 | 實際操作者使用 A 人工流程與 B 系統輔助流程，AB／BA 交叉分派，使用互異且難度相近的標單。保留分段工時、返工、錯誤、品質、次序及成對差。兩人只作先導，正式樣本量依變異、統計效力與退出率事前確認。現有真人 n=0。 |
| T04／T06／T10 工程安全與異常／候選 | 雙人獨立標註與裁決、原始分歧、規格及單位驗證，量價分開報混淆計數、Precision、Recall、FPR、棄答，另報 Top-K 及實測人工覆核成本。 |
| T05／T11 估算方法與是否採用 | 同案、同可用參考、同 K、同分母，報涵蓋、寬度、MAPE、成對區間分數與不確定性；列 3／4／5 群與消融。T11 屬獨立重建。 |
| T07～T09 匯入、效能、權限 | 隔離流程、逐請求日誌、估算及效能結果、角色狀態碼與稽核事件。正式部署需獨立授權驗收。 |

T05 採用須同時滿足相對區間分數改善 ≥5%、95% 成對建案 bootstrap 分數差區間完全低於零、距名義 70% 涵蓋率的絕對差惡化最多 5 個百分點、相對區間寬度增加最多 10%，並且 A1 不新增 A0 可估案例上的棄答。合成配對程序完成，採用門檻未達，維持 A0。研究樣本、參數與門檻維持凍結。

既有技術證據涵蓋 205 個已核對的封存成員。隔離 T07／T09 通過，T08 的 500／1,000 列 A0 HTTP 研究通過。三法同條件 HTTP 仍 PARTIAL，現有資料路徑及工作量不同。正式外驗待授權來源、工程真值與真人資料；樣本按[資料要求](SUPPLIER_CHECKLIST.md)開始收件，再由教授確認事前分析計畫。
