# T04 正式單位換算驗證

2026-11-22。用固定的合成單位主檔注入快取，直接執行正式 C# UnitConversionService.Convert。18 項全數通過。相容案例驗證數量、單價與換算係數，重量、長度、面積及體積均雙向測試，另查不可換算類別的同單位直通。拒絕案例包括跨維度、禁換不同單位、兩個方向的缺係數、未知合成單位、空白、null 和不存在的目標。

`dotnet run -c Release --project tools/graduation-synthetic/UnitContract`。
