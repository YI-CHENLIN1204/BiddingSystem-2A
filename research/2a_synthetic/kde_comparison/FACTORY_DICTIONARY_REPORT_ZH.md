# 專題書面報告用｜廠房材料字典規模實驗

## 實驗目的與方法

本實驗評估增加訓練字典的詞數，對合成廠房標單工項材料碼正確自動對應比例的影響。以 126 個訓練案建立精確名稱字典，工項名稱經 Unicode NFKC 正規化、去除前後空白並統一大小寫。名稱若對應多個材料碼則不自動對應。詞條以出現的訓練建案數由多至少排序，同分依正規化名稱與材料碼排序。不同字典規模採用同一排序的前綴，並對相同標單逐列評估。測試集排除已用於診斷的 SC 廠房 #16，剩 26 案、3,386 筆。驗證集有 27 案、3,644 筆。

## 實驗結果

| 訓練字典詞數 | 驗證集正確／3,644 | 測試集正確／3,386 | 測試集正確對應率 | 測試集待人工 | 測試集錯配 |
|---:|---:|---:|---:|---:|---:|
| 0 | 0 | 0 | 0.0% | 3,386 | 0 |
| 10 | 270 | 260 | 7.7% | 3,126 | 0 |
| 30 | 810 | 780 | 23.0% | 2,606 | 0 |
| 50 | 1,350 | 1,300 | 38.4% | 2,086 | 0 |
| 100 | 2,493 | 2,384 | 70.4% | 1,002 | 0 |
| 193 | 3,644 | 3,386 | 100.0% | 0 | 0 |

**表說**　廠房合成標單之精確名稱對應結果。正確對應率以全部測試工項為分母。0 詞時無自動命中，自動對應精確率不適用。

在同一批測試標單上，字典從 50 詞擴充至 100 詞，正確對應工項由 1,300 筆增至 2,384 筆，提升 32.0 個百分點。測試集名稱全曾出現在訓練集，完整字典的 100% 反映已知命名規則下的覆蓋程度。此測試以生成資料的材料碼為真值，未驗證陌生名稱、規格與單位衝突的安全性，也未量測人工工時或測試 KDE。

## 重現證據

在專案根目錄執行下列命令。第一個路徑指向已解壓縮的廠房資料根目錄，第二個路徑需為新輸出目錄。

```powershell
python research/2a_synthetic/kde_comparison/replay_factory_dictionary.py <factory-source> <new-output-dir>
```

程式核對來源雜湊和分割後輸出逐列 CSV、彙總 CSV 與 run manifest。可用 `dictionary_growth.csv` 的 `correct / total` 繪製曲線，圖名可用「廠房合成標單之訓練字典規模與材料碼正確對應率」。橫軸為詞數，縱軸為正確／全部（%），分驗證集（27 案）與測試集（26 案），從逐列 CSV 回查圖表數字。展示頁尚未建立。

## T02 訓練字典 67 詞對照

同一組凍結測試案，沿用訓練案出現次數排序及名稱精確比對。50／67／100 詞分別正確對應 1300／1742／2384 列（分母 3386），各組錯配 0。67 詞待審 1644 列，驗證集命中 1809／3644。測試名稱都曾出現在完整訓練集。正式 67 詞的實際內容與來源仍未核實，保留 NOT RUN。重跑原字典程式，指向新輸出目錄。[完整曲線](evening_results/dictionary_growth_67.csv)

## T01／T02 建案宏平均補測

每案先算正確列／明細列，再等權平均。驗證 27 案、測試 26 案，按建案重抽 2000 次，種子 20261122。測試 50／67／100 詞為 39.86%／53.41%／72.52%，67 詞的 95% 區間為 49.49–57.30%。只涵蓋凍結的合成已見名稱。從研究目錄執行 `python factory_dictionary_macro.py <mapping_per_item.csv> <output.csv>`。機讀結果位於 `evening_results/dictionary_macro.csv`。
