# 崴正營造 2A：公開工程資料集可行性評估（2026-11-10）

## 研究動機
廠商提供約 20 件歷史建案，分住宅／廠房及 RC／SC／SRC，部分組合可能只有 1–3 件。既有加權相似度、時間權重、P15/P50/P85 可以運算，但真實同質樣本不足，無法驗證正式工程估算可靠度。公開資料集不寫入 `HistoricalTransaction` 或崴正歷史標單，另建研究資料與實驗結果。

## 向教授報告的可行性結論
- **技術可行**：已找到可取得的台灣價格查詢、價格指數、海外材料強度 XLSX 與 BIM 模型。
- **數量模型「直接可用」尚未證實**：沒有驗證任何一份可以直接用於「台灣住宅／廠房 × RC／SC／SRC × 完整鋼筋／混凝土數量」的代表性多案資料集。
- **價格比較優先可做**：公共工程價格資料做外部價格對照、物價指數做跨年調價研究；不應將公共工程單價視為民間建案直接合理價格。
- **公開資料與崴正企業資料完全隔離**：研究用檔案／表、來源標籤、授權、版本、抽取日期及欄位口徑；企業已核准標單維持正式基準。
- **企業優先不是任意乘 3 倍**：比較企業-only、外部-only、部分池化，在可比真實案例留案驗證後才調權重。
- **不虛報信心度**：現階段輸出資料來源、有效案件數、權重 ESS、區間涵蓋率與回測誤差；沒有校準不顯示「93% 正確」。
- **研究停止原則**：如簡單模型達到工程師事先定義的驗收標準，停止搜尋複雜算法；如果仍無法驗證，只交付有人工複核的歷史比較與資料不足提示。

## 下一階段研究實驗
1. **FutuRaM 實檔審查**：下載 raw 與 consolidated，檢查欄位（建築類型／結構／建造年代／材料代碼／單位／樣本來源／面積定義）、資料筆數與授權；以來源 ID 去重。
2. **政府價格實檔審查**：人工查鋼筋／混凝土具體工項與單價口徑，確定是否可合法匯出；下載台灣月度建築工程物價指數，用於價格基期調整試驗。
3. **20 案適用性矩陣**：每案每材料／大項標記用途、結構、面積、日期、數量／金額完整性、決標真實性；不得拿工項行數當案件數。
4. **留一案回測**：企業單位用量中位數 vs 現行加權 P15/P50/P85 vs 結構硬相容與敏感度變體；僅以測試日期以前可得的歷史案訓練；在真實可比樣本不足時不宣稱模型勝出。
5. **外部資料是否加入**：只有欄位口徑、授權與可比性合格才做獨立外部基準與部分池化的對照；不能直接導入正式 HistoricalTransaction。

## 驗收（建議）
資料集欄位／授權核實，至少一個價格外部對照實例、一個材料用量資料清洗實例，以及企業來源與外部來源完全隔離的測試；工程上的可靠度仍需真實歷史案件回測。
