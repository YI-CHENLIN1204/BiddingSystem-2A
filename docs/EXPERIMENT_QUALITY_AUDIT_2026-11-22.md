# 2A 廠房研究：公平性、效度與可引用性獨立程式／CSV 稽核

日期：2026-11-22。識別：`research-quality-independent-audit-20261122`。正式系統及 Supabase **未變更**。
稽核對象：研究分支 `research/kde-comparison-20261122` 的 Python runner、結果 CSV、研究訓練資料生成器、交接及圖表。**本次是原始碼審閱、已封存 CSV 的獨立欄位及九層指標重算，不是重新執行全部模型或取得企業真實建案。**
本報告優先於研究分支更舊的「A0已證明較準／B1整套較差」用詞；不能替代既有 `FACTORY_FAIRNESS_AUDIT_ZH.md` 的數值一致性檢查。

## 一、整體裁決

- **可保留且可引用，須註明合成與探索性：** A0/A1 相同 26 件 test ×3 scope、每項相同8個歷史 IDs 與權重的純區間估計器比較；字典 **已見名稱** 的學習曲線；unit C# 18 項服務契約測試；固定工項的解析器微基準；合成壓力與程式不變性檢查。
- **不能當作完整演算法優劣結論：** 舊 A0/B1 的不等歷史樣本量、規格選取不同、面積口徑及未公開參數的組合比較。最新 `docs/EQUAL_SAMPLE_ALGORITHM_FAIRNESS_PROTOCOL_2026-11-22.md` 的 K5/K8 補測未在本輪稽核中觀察到已完成的可重現分數。不能用不等N的舊圖表宣稱對方算法整套敗給 A0，也不能將刻意限K的 B1-K 稱為原作者原法。
- **不能稱實際企業效益：** 193詞100%已知名稱命中、保守放行6.1%、人工作業節省7.7分鐘、TF-IDF Top3 70.8%、50k列1.42秒等都僅支持下述各自明確限定的量測。缺實際廠商標單、真人計時和完整API驗收。

## 二、實際驗證的數字

1. 檔案：`evening_results/factory_a0_a1_pairs.csv`。共**78筆案項、26個唯一test案、三項各26**，每筆 `refs` 與 `weights` 都是8個。**獨立由原CSV重新按 RC/SC/SRC × scope 九層平均**，70% A0相對 interval score = **0.5302134664**、A1 = **0.5025979998**；Coverage **0.5833333／0.6481481**；相對區間寬 **0.3622876／0.3881268**。與既有報告數值吻合。A1 點估計改善約 5.2%，其原本建案bootstrap 95%差異區間 **−0.071到+0.014** 跨零；沒有證據可聲稱其必然或穩定較優。
2. 檔案：`evening_results/factory_a0_b1_pairs.csv`。同26件 ×3 scope，可比真值相同，但原B1每scope有效參考案數：價格可估26件，**n=5～99**；混凝土和鋼筋各9件可估（**n=5～21**）、17件不足樣本（**n=0～4**）。A0則Top8。因此**舊A0/B1的「精度」不能作為嚴格等N比較**；9/26僅為共同可估子集。
3. Codex 新增 `factory_reference_provenance.py` 依 `projects.csv` 查得已封存引用紀錄皆屬 train、沒有目標自身。**A0 1,272筆引用中有699筆**、B1/B2 9,264筆引用中有4,528筆為目標**同日或之後**開工的歷史案。這些計數包含同一建案在不同案項/區間重用，**不是相異建案數**。原結果應標「回溯研究」；較早開工過濾屬獨立敏感度，不代表已驗證決標/入庫時確實可用。Codex已有兩法都過濾開工日的 A0/B1 補測，但**仍未控制有效歷史K一致**。

## 四、下一輪 Codex 的最少補測與PASS門檻

**P0（會改變方法採用決策）**：
1. 為材料總量與同規格細項各建一套明確、雙方一致的目標值／歷史候選資格；先用訓練和驗證檢查，不能臨時修改test真值。
2. 在**同一案項和同一合法候選池**做 A0-K5對B1-K5、A0-K8對B1-K8，從頭按該K重新估算；每案有`len(A0_refs)=len(B1_refs)=K`硬斷言，保留未達K的母體與棄答率。B1-K明寫研究修改版；原B1全群另做端到端可用率。
3. 以相同as-of可用日期、同一名義70%／90%和面積單位，再跑E1同ID估算及E2等K，另以開工日做代理敏感度。未發布或未知可用日不得偷偷認定已可參考。
4. 不改原result CSV與作者規格。新輸出逐案ref ID/n、拒絕原因、interval score、Coverage、Width、P50 MAPE、建案級不確定性、SHA、版本及 300dpi 圖。等K未完成前**完整算法公平勝負＝NOT RUN**。

**P1（可放專題報告但要重新標準化標題）**：
5. 材料字典「目前正式67詞 vs train-derived67詞」分開表、跨來源或新命名盲測、風險負例；真人計時前，工時只列情境推估。
6. 補完整API與隔離DB/歷史資格重播、工程異常真值、真正上傳路徑效能；排除保留之已知診斷case和報告中仍未能確認的來源。
7. 重寫Word中可疑標題/圖說：已見詞、情境推估、重建B1、共同可估子集n、as-of限制；不可以B1-only圖當A0/B1對比主證據。
