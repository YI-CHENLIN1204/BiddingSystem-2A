以材料主檔名稱匹配 `養護劑|脫模劑|脫膜劑` 為 0。目前這兩種只有指定產品規格計算，不是已有歷史資料。若未來要建歷史模型，需補真實有施作的適用案例與產品／面積／工法資料，不應為此重生整批住宅資料或強迫每案出現。

## 工項不必每案都有

現有標準材料共 100 種，但每案非忽略決標列涵蓋 **63–92 種不同材料**，並非每案全塞 100 種。這個數字只說明資料有缺項差異，不能證明每個缺項在工程上都合理。

使用者本輪確認：材料／工項依建案需要才出現。應明確區分：

| 情況 | 應處理方式 |
|---|---|
| 已確認不適用或未施作 | 合法缺項，不新增假工項，不因缺項判偏低 |
| 是否施作未知、資料漏列、對應尚未完成 | 標示待確認／資料不足，不當成 0，也不當成確定不適用 |
| 來源明確記錄數量 0 | 保留原始語意並核對，不以 0 作為缺項預設值 |
| 同材料只有部分範圍可讀 | 不以局部總量代替整案；來源不足要說明原因 |

現有 CSV／DB **沒有完整的逐案逐工項適用性標記或缺漏真值**，因此目前不能自動辨識每個缺項屬於哪一種。既有大宗估算對沒有所選標準材料來源的參考案會排除並顯示原因，不會自動補零；這也不等於判定該案不需要此材料。

後續擴充合成資料時，應先定義各案工項適用情境，再對適用部分產生數量；刻意漏項測試與合法未施作須在獨立真值檔區分。不要以獨立亂數把所有工項套到每一案，也不要用樣本數去虛構工程必要性。
