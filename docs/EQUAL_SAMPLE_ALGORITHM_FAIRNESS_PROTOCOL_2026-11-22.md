# 2A 嚴格等樣本數演算法公平比較協定

日期：2026-11-22。識別：equal-sample-fairness-correction-20261122。
**狀態：研究方法修正，等樣本數的 A0/B1 完整比較尚未執行（NOT RUN）。**

## 核心更正

使用者要求**同一批測試建案及每案項相同數量的有效歷史參考案**，並且要固定訓練/驗證/測試分割、材料/規格/單位/工料適用性、同一真值、同一計價口徑、同一名義區間與評分公式。不能以不同分母的精度或命中率宣布演算法優劣。

已執行的 A0 vs A1：相同26個廠房測試案 × 三種範圍 = 78案項，每案項同8個歷史參考案 ID、相同權重。**這是加權經驗分位數 vs 加權KDE的單變因比較**，不是外部報告完整演算法的對照。既有 5.2% 分數改善但配對重抽樣差異區間跨零的探索性結果可保留。

已執行的 A0 vs B1：A0 Top8，但外部報告 B1 從不同大小的最近群（原群大小5、7、15、99）取有效樣本，各 scope 有效歷史 n 不固定。原B1鋼筋和混凝土各僅9/26案可形成區間。**這不能稱為相同歷史樣本數的精度比較，且不能由此宣稱A0完整方法較準。** 保留舊數據作「原方法可用性/非等n探索性觀察」，不得覆寫。

## E1：只比較區間估算方法（已完成的同ID控制實驗）

A0和A1每案項的參考 ID 必須完全相同，均為8筆；資料值、材料規格、權重、有效期、面積分母及上下限機率一致，只能把加權分位數替換為加權高斯 KDE。A2等權版本要另列，不應稱外部作者完整方法。

## E2：比較選案加估算流程，兩法**有效歷史樣本數相同**（待執行）

相同訓練候選126件、驗證27件與主測試26件。每個目標案×結構體價格/混凝土/鋼筋用相同合格性、真值與可用日期。不把工項列數當獨立建案。

主分析固定**K=5**，次分析固定**K=8**；K指每個案項實際參與估算的有效歷史建案數，不是整批訓練集126件。

A0-K：在一致候選池內依正式相似度選出K件合格歷史，使用既有相似度與時間權重，重新計算分位數，不能取原Top8結果冒充Top5。

B1-K（**公平性控制變體，而非原作者完整原法**）：照外部報告八因子距離、平均連結分群與最近群選取，依對目標的距離排序群內合格同scope參考案，取前K件，群內等權高斯KDE。原文B1本來使用選中群內全部有效案，因此將其限制為K是一項研究修改，必須以B1-K命名。

若B1某目標scope未取得K件，該目標不進**等K預測品質**比較；另外報可用率及原因，不得把B1的2筆和A0的5筆相較，也不得造假補資料。若符合K5的只有9/26，就只對**相同9件**的兩法結果比較，不能外推至全部26件。K8須同樣條件。嚴格等K若太少，需增加有真值的新歷史資料再確認；擴張最近群外選案則須命名B1-EXT，不能當外部原法。

**注意**：比較兩套「選案方法」時，各自挑的參考案 ID 可以不同，否則選案本身無法比較；但歷史**筆數 K 必須相同**。比較「KDE區間計算」時則連 ID 和權重都要相同。

結構體價格的主對照固定相同幣值/金額範圍和總樓地板面積分母；外部報告原用基地/用地面積則另做分母敏感度，不能把分母差異歸因為KDE。

## 驗收、產出與決策

Codex建立離線 replay_factory_equal_n.py，逐案輸出 equal_sample_per_case.csv（test ID、scope、structure、K、A0/B1參考IDs、實際有效n、真值、分位、interval score、MAPE、Coverage、Width、候選與來源hash、排除原因）；輸出 equal_sample_summary.csv、equal_sample_verdict.md及300dpi PNG/SVG圖。必須有自動斷言 len(A0_refs)==len(B1_refs)==K、相同測試案/真值/單位/價格口徑/資料版本、所有refs來自train、無未來參考案、同名義70%（另90%）區間；失敗就報 FAIL/NOT RUN，不能宣稱公平勝負。

先在validation凍結B1-K同分破局及KDE參數，再跑test。同案成對評估、按建案重抽樣，保留n及不確定性。由於舊test早已檢視過，新K5/K8仍屬**探索性補測**，確認性結論須新的獨立資料。

舊的A0/B1非等K結果、A0/A1同8件結果以及外部原版B1全群可用率要**分開**呈現。**在E2實際PASS前，不能說完整的誰比較好、更不能據此換正式算法。** 正式5184/5264/Supabase保持原狀，只在獨立研究環境實驗。
