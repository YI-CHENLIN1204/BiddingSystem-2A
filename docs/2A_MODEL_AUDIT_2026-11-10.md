# 2A 量價模型與權重全面審查（2026-11-10，第一輪）

> 審查性質：程式碼查核＋Supabase 唯讀設定／樣本盤點；不是統計有效性驗收。**本輪不改動生產公式或資料庫。** 所有權重與門檻在真實可比資料的留案驗證前均視為「尚未校準」，不能宣稱已嚴謹驗證。

## 0. 資料基礎與實際設定

檢查分支 `feature/1d-api-integration`，主要服務：
- `ProjectSimilarityService.cs`：候選篩選、六項相似分數；
- `DetectionCategoryRangeService.cs`：材料用量、每平方公尺用量、相似／時間權重、加權百分位；
- `MajorCategoryPriceRangeService.cs`：大項金額、每坪價、權重與價格異常；
- `TwoAQuantityAnalysisService.cs`：待偵錯項目數量累加與高／低／正常；
- `EstimationSettingsService.cs`：參數設定與基本驗證；
- `TwoAPreprocessService.cs`：工項納入／排除，影響「材料總數量」可比性。

對現用 Supabase 專案只做 `SELECT`：`TopK=8`、`MinimumSampleCount=5`、`Lower/Median/UpperQuantile=0.15/0.50/0.85`、`SimilarityExponent=2`、`TimeHalfLifeYears=3`、`MinimumSimilarityScore=0`、`Structure/Area/SiteArea/Floor/Year/CityWeight=25/20/10/10/0/5`（總和 70）；面積與基地面積 cutoff 各 0.5、地上／地下樓層扣分率各 0.03／0.10、年份 cutoff 6 年（但 YearWeight=0）。

DB 中未刪除的 project_master 目前只有 10 件：8 件 Approved、2 件 Draft；8 件 Approved 全是「住宅＋RC」，其中 7 件建案**名稱**符合 DEMO／模擬／測試的提示規則。名稱檢查不是來源真實性認證；廠商表示有約 20 件原始建案，**不等於這 20 件已正式匯入目前 DB**。

## 1. 優先風險（由高至低）

| 級別 | 審查點／實際程式行為 | 風險、待驗證問題 | 建議 |
|---|---|---|---|
| P0 | **真實／模擬來源**：`HistoryStatus=Approved` 只表示已核准，未區分真實、合成、完整工程範圍。 | 7/8 名稱疑似模擬仍可能進入正式估算；模型結果只是 DEMO 流程驗證。 | 先盤點／標記來源與計量完整性，正式基準不得混入模擬。不可依名稱自動刪資料。 |
| P0 | **結構不同仍可納入**：`ProjectSimilarityService` 對 RC/SC/SRC 不同僅扣 `StructureWeight=25`；`MinimumSimilarityScore=0`。 | 若其他維度全部滿分，異結構得 `(70-25)/70=64.29%`，仍能被選入；不同結構鋼筋、混凝土、鋼骨用量不適合直接混合。 | 依材料類別研究結構硬門檻／人工允許的可比性規則。先做影響模擬，再改生產。 |
| P0 | **用量口徑與覆蓋率**：歷史同工程材料交易以 project 聚合，無證明「整案／部分」的欄位；待估也從工項累加。 | 完整鋼筋總量與局部工項比較，可能導致虛假的偏高／偏低。 | 每案每材料建立來源單位、範圍完整性、疑似重複計量與可信度審核。 |
| P0 | **價格大項完整性**：按相同工程大項求和，有金額就可能進入分布；缺項或拆／併計價無大項覆蓋率驗證。 | 部分結構體標單 vs 完整結構體價格比較；差異可能是工項範圍而非報價。 | 大項價格必須另做完整性／組成相容檢查，並紀錄計價年度；不要把材料純價與施工綜合價混用。 |
| P1 | **6 權重主觀設定**：25/20/10/10/0/5 並無實際真實案件驗證紀錄。 | 不代表各因子真實預測力；面積與基地面積可能高度相關，產生重複加權。 | 以留一案驗證、敏感度分析比較權重組，而非主觀認定為最優。 |
| P1 | **相似候選與 Top K**：先按相似分數排序取 `TopK=8`，時間權重只在取樣後作用。 | 較新但稍低相似度的案例可能被 TopK 截掉；TopK 固定 8 對 20 案小資料集也未校準。 | 比較 TopK=3/5/8/全部可比，以及按相似度／最終權重排序的差異。 |
| P1 | **最終權重**：`(SimilarityScore/100)^2 * 0.5^(abs(年代差)/3)`。 | 相似指數 2、半衰期 3 年均未校準；`abs` 可能讓目標日期之後的案例進入回溯測試，形成資料洩漏。 | 留案實驗只能使用目標日期前可得的資料；比較半衰期 0（不做時間衰減的實驗條件）、3、5、10 年。 |
| P1 | **有效樣本數**：現只檢查 `references.Count>=5`。 | 權重高度集中時名義 8 件，實際有效資訊可能遠少於 8 件；另外多筆同源模擬案不是獨立樣本。 | 計算 `ESS=(Σw)^2/Σ(w²)`，同時呈現獨立建案數及資料來源；不用 ESS 假裝有新增真實案。 |
| P1 | **P15/P50/P85 的解釋**：以累積權重的階梯式分位數；觀測超界直接紅燈。 | 8 案時端點跳動很大；70% 中心歷史分布**不等於**統計顯著異常、工程安全界限或預測覆蓋保證。 | 以留一案檢查區間涵蓋率／穩定性，必要時改為「歷史參考偏離」而非已認證異常。 |
| P1 | **價格時間變動**：歷史金額／歷史坪數直接比較（時間只降權）。 | 歷年材料行情、通膨、發包市場景氣不同；時間權重**不等於**價格平減／調價。 | 研究同一價格基期（公開價格指數等）；若無可靠指數，註明價格不可直接跨期比。 |
| P2 | **各因素的具體形狀**：樓地板／基地面積差達 50% 直接 0 分；城市必須完全一致才加 5；樓層按固定線性扣分。 | 截斷比例 50%、縣市界線與樓層扣分率是工程假設，並非驗證過的自然法則。 | 分別做分量敏感度及地區／規模擾動測試。 |
| P2 | **時間因素重複計入可能性**：設定有 `YearWeight`，當前=0；另有 `TimeHalfLifeYears=3`。 | 若將 YearWeight 調高，年代可能同時計入相似分數和時間衰減。 | 明確分開「工程年代對可比性」與「價格時間校正」，避免雙重計數。 |
| P2 | **常態分布檢查**：新增的 CV／偏態診斷是非判定用途，樣本 8 也不足確認常態。 | 把 `μ±1.96σ` 當「新的工程合格界限」會混淆預測、容忍與平均數信賴區間。 | 只做獨立研究比較，必要時使用考慮 n 不確定性的預測區間；目前不改正式判定。 |
| P2 | **信心度與模型版本**：目前能保存分析快照，但沒有校準過的準確率／區間可靠度。 | 顯示「97% 相似度」容易被誤解為「97% 預測正確」。 | 先做來源狀態、可比數量、ESS、留案誤差與區間覆蓋，再談可校準的信心度。 |

## 2. 對權重的具體挑戰

目前分數：`S=(25*結構一致分 + 20*面積距離分 + 10*基地距離分 + 10*樓層距離分 + 0*年代分 + 5*縣市一致分) / 70 * 100`，其中每分量按目前的相似度子函式處理，**不能把這個線性加總視為已校準的工程概率**。

- 結構錯誤扣 25/70=35.71 個百分點；「RC 與 SC 不同」仍最高 64.29%，無最低分門檻時仍有資格。
- 面積權重 20/70=28.57%，基地面積 10/70=14.29%；兩者共 42.86%，但高度相關的可能性需實證檢查。
- 地上樓層差 1 層只扣 10*0.03/70*100=0.43 個百分點；地下樓層差 1 層扣 10*0.10/70*100=1.43 百分點。這些差異是否合理應以數量預估誤差測試。
- 城市不同扣 5/70=7.14 個百分點，即使跨縣市相鄰的工程也沒有部分分數。
- 年份 0 權重：年代**未直接進相似度**，但三年半衰期仍使年代影響分位數；不能說現在完全沒有考慮時間。
- 特別注意：數量估算與價格估算**目前共用同一套相似權重**；就算對鋼筋量最好的權重也未必對結構大項價格最好，必須獨立驗證。

## 3. 先研究、再決策的模型比較實驗

前提：廠商原始 20 件建案先做資料健康檢查（住宅／廠房 × RC/SC/SRC；完整數量／大項價格／計價年月／單位／標單範圍），只使用**不同且真實可比**的建案作留案測試。不要把 590 筆標單工項當成 590 件獨立歷史案。

**候選版本（從簡到繁，避免無止盡開發）：**
1. 基準 A：同類型＋結構條件相容，直接用歷史單位用量中位數；價格按工程範圍一致的每坪價中位數。
2. 現行 B：六特徵加權相似度、時間半衰期、加權 P15/P50/P85（作為 baseline，不先視為最佳）。
3. 候選 C：強制結構相容／必要時逐層擴展非關鍵條件，加權百分位數；比較 TopK 與敏感度。
4. 候選 D：若發現可比、授權可用的公開資料，**獨立外部基準**與企業基準比較，再研究分層／部分池化；不得混入企業歷史成交資料。
5. 常態／對數常態僅列為對照研究；不得用模擬資料挑出「最佳」正式演算法。

**每個留案測試需彙整：**單位用量預測誤差（MAE/MAPE 在分母非 0 時）、P15-P85 區間涵蓋率（目標理論 70% 不是保證）、區間寬度、ESS、每類樣本數、敏感度（移走一案區間變動）、來源與價格範圍一致性。此數據樣本太少時，統計變異需誠實標註，不對外宣稱可靠的信心度百分比。

**研究停止條件**：選擇最簡單且通過事先約定驗收標準（工程師確認數量口徑，且留案誤差／區間涵蓋／穩定度可接受）的方案；若資料不足而無法做有效驗證，交付「歷史參考＋人工複核＋資料不足提示」版本，不為湊數據改用更複雜模型。

## 結論

**程式能執行 ≠ 權重經驗證 ≠ 異常結果可靠。** 目前已查得兩項最急迫風險：異結構未硬排除且相似度門檻 0、模擬案在 Approved 候選中。正式調整權重之前先解決來源與可比條件；不再對 8 件模擬案過度調參。
