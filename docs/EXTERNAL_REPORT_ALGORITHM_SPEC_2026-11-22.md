## 2. 第3.2節：工項章節分類 C1

1. 分別用**住宅與廠房**歷史工項名稱、工程章節建立章節特徵；依建物類型選對應模型。
2. 分類先依**既定順序**比對工項名稱是否包含關鍵字；命中就採對應章節並記命中字串；報告用「100% 信心」標記規則直接對應，**它不是經校準的真實正確率**。
3. 未命中才將工項名稱轉連續字元 **1/2/3 gram**。每個章節 j：`TF(t,j)=c(t,j)/N_j`；`IDF(t)=ln[(C+1)/(df(t)+1)]+1`；`v_j(t)=TF(t,j)*IDF(t)`。與查詢向量 q 的餘弦相似 `cos(q,v_j)=(q·v_j)/(|q||v_j|)`；章節分數為 `100*cos`、取一位小數，最高分章節勝出。
4. 沒有有效特徵或最高分為0→`未分類`。報告「分類信心度」是 `最高章節分數/所有章節分數總和*100%`，**僅相對分數，非統計校準機率**；需展示各章節候選與人工覆核。
5. **未完整指定**：前處理與特殊符號空白、查詢向量 q 的 TF 定義、關鍵字清單及順序、相同章節分數的 tie-break、學習/測試來源切分。若無原始碼，C1 只能標「依報告重建／實作假設」，不聲稱 exact reproduction。
6. 報告第3.2.5節將「2000 PSI預拌混凝土280m³＋2000 PSI混凝土澆置520m³=800m³」當例子。**工程審核警示**：工料與澆置可能涵蓋同一實物，不能未經計價/工程範圍審查便當可安全加總的金額或數量；研究應保留報告例子的原義，另列工料重複計量風險，不擅自改成安全政策或企業真值。

## 3. 第3.3～3.4節：歷史篩選與八特徵分群 B1

- 候選：已有最終標單、可用工程明細、正值總樓地板面積。與 2A 正式篩選不同，**報告允許不同用途/構造類型進入候選並以距離扣分**。相同來源檔可在檔案大小相同時比較 SHA256 排除自身；修改版可由使用者指定原建案以排除。研究中需一律用穩定 ID 排除任何真值相同案，不能只依 SHA 保護。
- 8 個權重（總和100%）：

| 條件 | 權重 | 報告的差異口徑 |
|---|---:|---|
| 總樓地板面積 | 30% | 相對差 |
| 建物類型 | 15% | 同0、異1 |
| 構造類型 | 7% | 同0、異1 |
| 地上樓層數 | 11% | 相對差 |
| 地下樓層數 | 7% | 相對差 |
| 總用地面積 | 5% | 相對差 |
| 地區 | 20% | 同縣市0、異1 |
| 年度 | 5% | min(1, abs(year difference)/year scale)，例子使用10年尺度 |

- 面積及樓層：`d(a,b)=min(1,abs(a-b)/max(a,1))`，a=目標案。確認雙方皆無地下室→差異0。**目標缺**選填用地面積或樓層→0.5；目標有填但**參考缺**→1。地區名稱規一化後只比縣市。參考年度缺→1。
- `D(A,B)=100*SUM(weight_k*d_k)`，`S=100-D`。報告示例（樓板 10000 vs 12000、住宅RC、地上10 vs12、地下2 vs1、用地2000 vs2500、臺中 vs彰化、2020 vs2018、年尺度10）得 **D=33.95，四捨五入34.0；S=66.0**。建立金標測試，但請保留未四捨五入原值以排序。
- 因相對差異方向不對稱，**歷史-歷史**距離矩陣用 `D_s(A,B)=(D(A,B)+D(B,A))/2`。
- 每個歷史案開始為獨立群，**平均連結 hierarchical agglomerative**：`L(G,H) = sum_{g∈G,h∈H} D_s(g,h)/(|G|*|H|)`，反覆合併距離最小群，直到設定群數。對**本案**每個群計算 `mean_{g∈G}D(target,g)`，選平均距離最低的群；**本案不加入歷史建案重新訓練分群**。
- 群內每一個估算 scope 再單獨排除不適用、缺面積或無資料建案；每案每scope最多1個可用值。報告示例有效樣本4/3/1，並以「最低3筆」作**算例**，不是有證據證明實際預設門檻3。
- **原文未固定**：要設定的群數 K、群數搜尋法、群間距離 ties、日期缺值完整規則與年度尺度的全域設定、章節白名單、最低有效樣本正式配置。**這些必須在實驗 manifest 中標 `RECONSTRUCTION_ASSUMPTION`**；沒有原作者參數前不能說是逐行忠實重現。

## 4. 第3.5節：B1 群內等權 Gaussian KDE

1. 選定群後，對各項 scope 取得 `x_1,...,x_n`。**每個有效參考案等權1/n**，不能把 2A 的相似/時間權重帶到 B1。
2. Gaussian kernel：`K(z)=exp(-z^2/2)/sqrt(2*pi)`；`f_h(x)=(1/(n*h))*SUM_i K((x-x_i)/h)`。
3. 帶寬 **single-mode critical bandwidth**：先 `R=max(x)-min(x)`，若 R=0 → 報告指定顯示**資料不足**（不是自行給任意 h）；轉 `z_i=(x_i-min(x))/R`。二分搜尋標準化帶寬，規則網格＋原始樣本位置看 KDE 的導數正→負峰數，搜尋到「最小近似單峰帶寬」，最後 `h=h_normalized*R`。報告導數式 `f'_h(x)=Σ_i(x_i-x)*K((x-x_i)/h)/(n*h^3)`。
4. `F_h(x)=(1/n)*SUM_i Φ((x-x_i)/h)`；所有工程價與量取非負，`F_plus(x)=(F_h(x)-F_h(0))/(1-F_h(0))` for x≥0。分位 q 下限/上限由二分搜尋 `F_plus(x)=α,1-α`，`α=(1-r)/2`。**原報告主示例 r=90%（P5/P95）**；公平消融研究另固定雙方法 70%，不能標成作者原本設定的主例。
5. 報告三案示例 x=[0.040,0.050,0.060] m³/m²：`R=0.020`、標準化約 `h=0.2425`、實際約 `0.00485`，r=90% 上下限約 `0.034954／0.065046` m³/m²，目標樓板10000m²→約 **349.54～650.46m³**。數值應作**容差金標**，不要為逼近報告小數而用 test 真值調帶寬。
6. **未固定**：初始帶寬上下界、最大迭代數、峰判定網格密度、正負導數容忍度、CDF 根求解容差、KDE極端值保護。Codex 必須「可重現地選定」並寫 manifest，但對 B1 標記重建假設；未取得原作者程式就不能宣稱與原作者實際計算完全一樣。

## 5. 第3.6～3.7節：面積倍率、偏差與判定

- **結構體價格**：每個歷史案結構體工項複價合計 `M_i=SUM_r amount_{i,r}`，歷史值 `x_i=M_i/B_i`，其中 B_i=**總用地面積 m²**。估出單位面積分位後乘目標總用地面積 B0；不能直接與正式2A「每坪總樓地板單價」混為同一數值單位。
- **細項用量**：同規格、同單位、同 scope 的明細若適合加總，`Q_{i,k}=SUM_r q_{i,k,r}`，歷史值 `x_{i,k}=Q_{i,k}/A_i`，其中 A_i=**總樓地板面積 m²**；估出的分位乘目標 A0。缺歷史面積/規格/數值者排除該scope，缺目標面積→資料不足。
- 區間內含等號 `L<=y<=U` → 範圍內；`y>U` 時 `(y-U)/U*100%` 表示偏高，`y<L` 時 `(y-L)/L*100%` 表示偏低（符號為負）。只要 `abs(deviation)>τ` 才標「需複核」，≤τ 顯示「容許偏差內」。報告示範 `τ=5%`，**不能斷言這就是作者正式預設值**。若區間不可算→資料不足。上下限為0時先標未定義或人工審核，別默默除以0。
- 報告價格示例：3個歷史案 1600m²/1600萬元、2000m²/2500萬元、2400m²/3600萬元，x=10000/12500/15000 元/m²；P5/P95約 8738.42～16261.58 元/m²，目標B0=2000m²得約 **17476839～32523161 元**。為正規容差案例，不可用 test 資料反向校準。
